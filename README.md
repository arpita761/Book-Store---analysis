# Bookstore Analysis

Practice project in two parts, built while learning data analysis.

## Part 1: SQL (PostgreSQL)
- File: `sql bookstore project.sql`
- Database with Books, Customers and Orders tables (primary and foreign keys)
- Queries cover filtering, joins, GROUP BY with HAVING, aggregate functions, sorting and LIMIT
- Examples: revenue, books sold per genre and author, top customers

## Part 2: Excel
- File: `BOOK STORE PROJECT 2.xlsx`
- Separate sample dataset analyzed with formulas, Pivot Tables and charts

Note: the two parts use different datasets. Both are practice projects.
